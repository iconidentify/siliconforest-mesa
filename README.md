# SiliconForest Mesa: experimental/m4

Eryk's M4 development and qualification evidence. This is a separate, older driver and firmware contract; it is not a universal or release-qualified M4 driver.

Source: `08b19ec3a2e422a7252fdfe77c185450fccf86da` (`eryk-legacy/m4-asahi-port`).
Original authorship, licensing and history are retained. This branch adds only
the personal fork policy and this branch notice, and removes the obsolete
inherited macOS workflow. It has not been built or tested
by the SiliconForest combined-integration validation run.

See the [main integration](https://github.com/iconidentify/siliconforest-mesa/tree/siliconforest/next)
for the hardware matrix, exact source inventory, build instructions and validation.
Do not install this experimental snapshot over a working system without a
matched hardware qualification and a recovery path.
